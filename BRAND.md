# Graphite Industries Limited — approved visual system

| Role | Colour |
|---|---|
| Primary | Graphite Charcoal `#25282A` |
| Secondary | Mineral Silver `#A7ADB0` |
| Accent | Deep Forest Green `#174A3A` |
| Highlight | Premium Gold `#C6A15B` |
| Main background | Clean White `#FFFFFF` |
| Supporting background | Soft Grey `#F2F3F3` |

Montserrat for headings. Open Sans for body text. Roboto Mono for selected technical labels and numeric highlights. Gold is used sparingly for dark-background accents; silver supports secondary text on dark surfaces. Use darker grey for readable small body text on white. The supplied logo is preserved rather than recoloured.
